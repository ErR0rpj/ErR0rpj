Stavan is a live music, video, and community platform dedicated to Jainism. Since **2021**, I've architected and maintained a production-grade ecosystem serving a passionate community.

** Core Technologies:**
`
Golang  gRPC  Redis  Flutter  MongoDB  Docker  Kubernetes
`

** Key Achievements:**
-  Designed scalable backend architecture for **5000+ concurrent users**
-  Built real-time features using **Redis Pub/Sub** for instant notifications
-  Achieved **99.9% uptime** with automated failover mechanisms
-  Mentored **3+ interns** through complete product lifecycle
-  Grew community from **0 to 1000+ active contributors**
