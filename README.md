Stavan is a live music, video, and community platform dedicated to Jainism. Since 2021, I've built and maintained a thriving ecosystem that serves:
- **5000+ daily active users** across all platforms
- **40,000+ downloads** on mobile platforms
- **4.8/5 star rating** on Google Play Store
- **1000+ community members** who have personally reached out to contribute

**Core Technologies:** Golang | gRPC | Redis | Flutter | MongoDB | Docker | Kubernetes

**Key Achievements:**
- Designed and implemented scalable backend architecture supporting 5000+ concurrent users
- Built real-time features using Redis Pub/Sub for instant notifications and live streaming
- Developed cross-platform mobile application reaching 40K+ users
- Managed team of 3+ interns in designing and improving the application
